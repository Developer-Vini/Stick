### How do I run it?
Just click on this link: https://developer-vini.github.io/Stick/

### Run locally

Clone the repository(git clone https://github.com/Developer-Vini/Stick) and open the `index.html` file in your browser. No installation or additional setup is required.

### How to use it?

Simply click on the square you want to add to, then enter your name or any message you'd like to display.

The website was developed using:
- JavaScript, 
- HTML, 
- CSS.
